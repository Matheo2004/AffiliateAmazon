# Site d'affiliation Amazon

Site vitrine statique réalisé en 2023 pour présenter des produits Amazon au moyen de liens d'affiliation.

## Pages

Accueil, produits, catégories, blog, avis, FAQ, à propos, contact, mentions de divulgation et conditions d'utilisation.

## Technologies

HTML, CSS, JavaScript, avec des animations au défilement grâce à GSAP (ScrollTrigger) et des effets 3D (CSS3DRenderer).

## Voir le site

Ouvrir `index.html` dans un navigateur : aucune installation n'est nécessaire.
